# 数据库设计原则

良好的数据库设计对于高效的数据管理至关重要。

## 规范化

规范化是组织数据以最小化冗余的过程。

### 第一范式 (1NF)
- 消除重复组
- 为每个组创建单独的表

### 第二范式 (2NF)
- 满足 1NF 的所有要求
- 消除部分依赖

### 第三范式 (3NF)
- 满足 2NF 的所有要求
- 消除传递依赖

## 索引

索引可以提高查询性能。

```sql
CREATE INDEX idx_users_email ON users(email);
```

## 关系

- 一对一
- 一对多
- 多对多
